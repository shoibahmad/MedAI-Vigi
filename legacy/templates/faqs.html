Frequently Asked Questions

Find answers to common questions about PhenoRx

General Questions

What is PhenoRx?

PhenoRx is an advanced AI-powered system designed for automated adverse drug reaction (ADR) identification and clinical decision support. It combines machine learning algorithms with Google's Gemini AI to provide comprehensive drug safety analysis, interaction checking, and personalized dosing recommendations for healthcare professionals.

Who developed PhenoRx?

PhenoRx was developed by Pharm.D students at Integral University, Lucknow, as part of their research project in clinical pharmacy and pharmacovigilance. The system represents the integration of pharmaceutical knowledge with modern artificial intelligence technology.

Is PhenoRx a replacement for clinical judgment?

No. PhenoRx is a clinical decision support tool designed to assist healthcare professionals, not replace them. All predictions, recommendations, and analyses should be reviewed and validated by qualified healthcare professionals before implementation. The system supplements professional medical judgment with data-driven insights.

Features & Functionality

What features does PhenoRx offer?

PhenoRx offers several key features:
  • ADR Risk Assessment with probability scores
  • Real-time Drug Interaction Checking
  • Personalized Dosing Recommendations
  • Pharmacogenomic Analysis
  • Therapeutic Drug Monitoring Tools
  • AI-Powered Clinical Insights
  • Comprehensive Medical Report Generation

How accurate is the ADR prediction?

The ADR prediction model is trained on clinical data and provides probability scores with confidence intervals. While the system demonstrates high accuracy in testing, it should be used as one of many tools in clinical decision-making. The AI analysis provides additional context and reasoning to support the predictions.

Can I check interactions between multiple drugs?

Yes! The Drug Interactions module allows you to add multiple medications and check for interactions between all combinations. The system provides severity levels (major, moderate, minor) and specific recommendations for each interaction detected.

Usage & Access

Who can use PhenoRx?

PhenoRx is designed for healthcare professionals including:
  • Physicians and Medical Doctors
  • Clinical Pharmacists
  • Pharmacy Students and Residents
  • Nurses and Healthcare Providers
  • Clinical Researchers
The system requires medical knowledge to interpret results appropriately.

Is there a mobile version available?

The web interface is fully responsive and works on mobile devices, tablets, and desktops. You can access PhenoRx through any modern web browser on your mobile device. A dedicated mobile app may be developed in the future based on user feedback.

Do I need to create an account?

Currently, the system does not require account creation for basic usage. However, patient information and assessment results are stored in your browser's session storage. For production deployment, user accounts may be implemented to enable data persistence and multi-device access.

Privacy & Security

Is patient data secure?

Patient data security is a priority. Currently, data is stored locally in your browser and not transmitted to external servers except for AI analysis. For production deployment, appropriate security measures including encryption, secure authentication, and HIPAA compliance would be implemented. Please refer to our Privacy Policy for detailed information.

How is AI used in the system?

PhenoRx uses two types of AI:
  • Machine Learning Models: Trained on clinical data for ADR prediction
  • Google Gemini AI: Provides natural language analysis and clinical insights
The AI components enhance the system's capabilities but all recommendations should be validated by healthcare professionals.
