API Reference

Complete API documentation for PhenoRx integration

Base URL

http://localhost:5000

Replace with your production URL when deployed.

Authentication

Currently, the API does not require authentication for local development. For production deployment, implement appropriate authentication mechanisms.

Endpoints

POST /predict

Predict adverse drug reaction risk based on patient data.

Request Body

Parameter Type Required Description
age integer Yes Patient age (0-120)
gender string Yes "Male" or "Female"
weight float Yes Weight in kg
height float Yes Height in cm
medication string Yes Medication name
dose string Yes Medication dose

Example Request

{ "age": 65, "gender": "Male", "weight": 75, "height": 170, "medication": "Warfarin", "dose": "5mg", "route": "Oral", "duration": "Long-term" }

Response

{ "adr_probability": 0.65, "risk_level": "High", "confidence": 0.85, "gemini_analysis": "Detailed AI analysis...", "recommendations": [ "Monitor INR closely", "Watch for bleeding signs" ] }
POST /check-drug-interactions

Check for interactions between multiple medications.

Request Body

{ "medications": [ {"name": "Warfarin", "dose": "5mg"}, {"name": "Aspirin", "dose": "81mg"} ] }

Response

{ "interactions": [ { "drug1": "Warfarin", "drug2": "Aspirin", "severity": "major", "description": "Increased bleeding risk", "recommendation": "Monitor INR closely" } ], "ai_insights": "Detailed analysis..." }
POST /personalized-dosing

Calculate personalized medication dosing based on patient factors.

Request Body

{ "medication": "Warfarin", "standard_dose": 5, "age": 70, "weight": 65, "creatinine": 1.2, "egfr": 55, "cyp2c9": "Intermediate" }

Response

{ "recommended_dose": 3.5, "dose_adjustment_factor": 0.7, "rationale": [ "Age factor: 20% reduction", "Renal factor: 30% reduction" ], "monitoring_requirements": {...} }

Error Codes

Code Description
200 Success
400 Bad Request - Invalid parameters
404 Not Found - Endpoint doesn't exist
500 Internal Server Error

Rate Limiting

Currently no rate limiting is implemented for local development. For production, consider implementing rate limiting to prevent abuse.
